

1.QUESTION:  Explain the difference between <em> and <i>. When would you use each?

ANSWER: The <em> tag is used when text needs emphasis and carries meaning. Screen readers usually announce emphasized text differently, helping users understand its importance.

The <i> tag is generally used for text that is visually different from surrounding content without adding emphasis. Examples include foreign words, technical terms, or book titles.

Example using <em>:

"You must submit the assignment before Saturday."

Here, "must" is important and deserves emphasis.

Example using <i>:

"The French word <i>bonjour</i> means hello."

In this case, the word is simply presented in a different style because it is a foreign term we also use it alot in naming scientific name of things and animals.



2.QUESTIONS:  List at least 3 HTML elements with special screen reader behavior and explain why.

1. ANSWERS: <button>

Screen readers automatically announce it as a button.

Users know it is interactive and can be activated.


2. <nav>

Screen readers recognize it as a navigation landmark.

Users can quickly jump between navigation sections.


3. <main>

Identifies the primary content of the page.

Helps users skip repetitive navigation and go directly to important content.


4. <form>

Signals that a section contains user input controls.

Helps screen reader users understand when they are dealing with a form.

WHY?

Browsers handle these elements specially because they provide meaningful information about the page structure and improve accessibility for everyone and also helps in maintenance
