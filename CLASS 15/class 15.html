CSS Box Model + Margin Question The CSS box model has 4 parts: +----------------------+ | Margin | | +----------------+ | | | Border | | | | +------------+ | | | | | Padding | | | | | | +--------+ | | | | | | |Content | | | | | | | +--------+ | | | | | +------------+ | | | +----------------+ | +----------------------+ Content → actual text/images inside Padding → space inside the element around content Border → line around padding/content Margin → space outside the element If: margin-bottom:20px; margin-top:30px; Space between them: Answer = 30px Why? Because of margin collapsing. Vertical margins collapse into one margin, and the largest margin wins. So: 20px + 30px ≠ 50px Final space = 30px 2. CSS Specificity Hierarchy Specificity order: Inline Styles ↓ ID Selectors (#) ↓ Classes, Attributes, Pseudo classes (.) ↓ Elements (div, p, h1) Calculate each selector: A) .header nav ul li a Specificity: .header = 0,1,0 nav ul li a = 0,0,4 Total: 0,1,4 B) nav a.active Specificity: .active = 0,1,0 nav a = 0,0,2 Total: 0,1,2 C) .nav-links a Specificity: .nav-links = 0,1,0 a = 0,0,1 Total: 0,1,1 Winner: .header nav ul li a because: 0,1,4 is greater than: 0,1,2 and: 0,1,1 3. What is CSS Cascade? The cascade is the rule CSS uses to decide: "Which style should apply when multiple styles target the same element?" CSS decides using: Importance (!important) Specificity Order of appearance Example Instead of writing: h1{ color:black; } .card h1{ color:black; } .hero h1{ color:black; } You can simply write: h1{ color:black; } Because all headings already inherit that style. Understanding cascade helps avoid writing duplicate CSS. ENGINEERING THINKING 1. Padding Makes Element Wider Problem You set: width:200px; padding:10px; But the element becomes wider. Why? Default CSS uses: box-sizing:content-box; Which means: Total width = content width + padding + border Example: 200px width +10 left padding +10 right padding = 220px Fix: Use: box-sizing:border-box; Now padding is included inside the width.
